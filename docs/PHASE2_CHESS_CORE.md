# Phase 2 — Chess Core\n\nImplemented a strict six-field FEN parser with structural checks for the eight ranks, each rank width, FEN empty-run notation, piece symbols, king count, material limits, pawn placement, active color, castling metadata, en-passant metadata, and move counters. The position model supports square lookup and FEN round-trip serialization.\n\nThis is a structural FEN validator, not a complete chess legality engine. It does not determine check, king adjacency, legal move reachability, pins, repetition, or full game history. A dedicated rules engine is required for those checks.\n
